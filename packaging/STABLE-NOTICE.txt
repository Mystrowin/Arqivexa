This release is intended for Windows 11 x64 on local NTFS storage. CFS archives
are not encrypted. Protect archives using Windows access controls and separate
backup practices where confidentiality is required.

The installer is signed with the CFS self-signed publisher certificate. Windows
may still show an Unknown Publisher or SmartScreen warning until the user has
explicitly chosen to trust that exact certificate. CFS never installs a general
root certificate authority.

Only publish this notice with an installer that has passed the complete installed
artifact acceptance checks. Do not treat a development or partial package as a
Stable release.
