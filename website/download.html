03

Installation

Prepare Windows and open your first archive.

Check the system

Arqivexa 0.6.0 Stable targets Windows 11 x64. Writable archives must be stored on a local NTFS volume.

Enable Projected File System

Setup checks for the Windows Client-ProjFS feature and may ask to enable it. Restart Windows if requested before testing Explorer mounting. If ProjFS is unavailable, Arqivexa reports the issue instead of silently switching to full extraction.

Open or create a .cfs archive

After setup, open a supported archive from File Explorer or use the supported creation commands. Let pending changes finish saving before closing the workspace.

The installer filename remains CFS-0.6.0-Stable-Setup.exe because it was signed before the Arqivexa rebrand.

04

Security and data

Know what the app and website do.

Installer signing

The 0.6.0 installer and shipped executables are Authenticode-signed and timestamped with the existing CFS self-signed publisher certificate. Windows may show Unknown Publisher or SmartScreen until that exact certificate is trusted. Arqivexa does not install a general root certificate authority.

Updates require approval

Update downloads are checked against the expected SHA-256 and pinned publisher identity. Arqivexa asks before downloading or launching an update and requests administrator approval when needed.

Archive work and diagnostics

Normal compression, mounting, saving, and recovery keep archive contents local. Optional diagnostic reports can be disabled. Local logs are designed to omit archive contents, filenames, credentials, access tokens, and certificate private keys; review logs before sharing them.

App privacy and diagnostics details

Website analytics

This website uses Google Analytics to measure visits. Website analytics are separate from the app's local archive processing. See Google's Privacy Policy.

Keep separate backups

Arqivexa is not backup software and does not encrypt archives. Keep another copy of important files and use separate protection when confidentiality is required.
