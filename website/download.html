02 / INSTALL

Prepare Windows and open an archive.

Arqivexa reports when a required Windows feature is unavailable. It does not silently switch to full extraction.

Check the system.

Use Windows 11 x64. Writable archives must be stored on a local NTFS volume.

Enable Projected File System.

Setup checks for Client-ProjFS and may ask to enable it. Restart Windows if requested before testing Explorer mounting.

Open or create a .cfs file.

Use File Explorer or the supported creation commands. Let pending changes finish saving before closing the workspace.

03 / SECURITY AND DATA

Know what the installer and app do.

Review signing and privacy details before installing or sharing diagnostics.

Installer signing

The 0.6.0 installer and shipped executables are Authenticode-signed and timestamped with the existing CFS self-signed publisher certificate. Windows may show Unknown Publisher or SmartScreen until that exact certificate is trusted. Arqivexa does not install a general root certificate authority.

Updates require approval

Update downloads are checked against the expected SHA-256 and pinned publisher identity. Arqivexa asks before downloading or launching an update and requests administrator approval when needed.

Archive data and diagnostics

Normal compression, mounting, saving, and recovery keep archive contents local. Optional diagnostic reports can be disabled. Local logs are designed to omit archive contents, filenames, credentials, access tokens, and certificate private keys; review logs before sharing them. App privacy details ↗

Website analytics

The website uses Google Analytics to measure visits. This is separate from the app’s local archive processing. Read Google’s Privacy Policy ↗.
