Guides / Archive editing

Explorer-first editing

Edit compressed files without extracting the entire archive first.

Traditional archive editing often means extract, modify, and compress again. Arqivexa takes a different approach for supported .cfs archives: it exposes a folder-like workspace in Windows File Explorer and provides file contents on demand.

01

The problem

Why full extraction can be inconvenient.

Extra temporary storage

Extracting an archive can temporarily require both the compressed archive and an uncompressed copy of its contents. That may be unnecessary when you only need a few files.

Extra workflow steps

The usual sequence is extract, find the file, edit it, rebuild the archive, then replace the old copy. Arqivexa is designed to reduce those steps for its own supported format.

One archive to manage

The user-managed object remains the .cfs archive. The Explorer workspace is a projected view used while the archive is open.

02

How Arqivexa does it

Directory first, contents on demand.

Open the archive

When a supported .cfs archive is opened, Arqivexa creates a Windows Projected File System workspace that File Explorer can browse like a directory.

Hydrate only requested files

File data is supplied when an application actually requests it. Arqivexa does not need to expand every file in the archive just to display the directory tree.

Persist supported edits

Supported changes made in the mounted workspace can be committed back into the archive. Close, recovery, validation and optimization are handled as separate lifecycle operations.

03

Supported editing

What “editable archive” means in the current release.

Common file operations

The design supports ordinary workspace operations such as reading files, overwriting supported files, creating files, renaming entries, moving entries and deleting entries.

Application behavior can vary

Some Windows applications use unusual save patterns, memory mapping, file locks, temporary replacement files, antivirus hooks or preview handlers. Arqivexa does not claim universal compatibility with every access pattern.

Keep backups

Arqivexa is archive software, not a backup system. Keep independent copies of important or irreplaceable data.
