FAQ / QUICK ANSWERS

Questions, with clear boundaries.

Short answers about the Explorer workflow, supported systems, saved edits, and what Arqivexa does not promise.

01 / BASICS

What Arqivexa does.

Start with the product and its archive format.

What does Arqivexa do?

Arqivexa opens supported .cfs compressed archives as folder-like workspaces in Windows File Explorer. You can browse files on demand and save supported edits back into the archive.

Does it extract the whole archive first?

Not in the normal ProjFS workflow. Arqivexa projects the directory structure and supplies file contents as applications request them.

Is .cfs the product name?

No. The product is Arqivexa. The .cfs extension is retained from the project’s former CFS name for compatibility with existing archives and integrations.

02 / COMPATIBILITY

Systems and apps.

Current Stable support has a defined scope.

Which Windows version is supported?

Arqivexa 0.6.0 Stable targets Windows 11 x64.

Where can writable archives live?

The current Stable support scope requires writable archives to be stored on local NTFS storage.

Will every Windows application work?

No universal compatibility guarantee is made. Preview handlers, antivirus, indexing, memory mapping, and application-specific access patterns can affect hydration and behavior. Test unfamiliar software with a copy.

03 / EDITING

Changes and storage.

How edits are committed and how the format compresses files.

Are edits saved back into the archive?

Supported mounted edits are saved back into the archive. Ordinary changes are committed after a quiet period; explicit commit, close, discard, and recovery actions remain separate.

Can an archive grow after editing?

Yes. Updates can append changed data and manifests. After closing the workspace, Optimize can transactionally remove obsolete archive history.

Is the compression solid?

No. The current release uses independent per-file LZMA2 compression rather than one solid compressed stream across the entire archive. Solid compression can be smaller for some collections of similar files.

04 / SECURITY

Protection and trust.

Compression does not replace backup or encryption.

Does Arqivexa encrypt archives?

No. The current release compresses archive contents but does not provide password protection or encryption.

Is Arqivexa a backup system?

No. Keep an independent, separately accessible backup of important or irreplaceable files.

Why might Windows warn about the installer?

The 0.6.0 release uses a self-signed Authenticode publisher certificate. Windows may show Unknown Publisher or SmartScreen until that exact certificate is explicitly trusted. Arqivexa does not install a general root certificate authority. Read signing details.

06 / TOOL CHOICE

Arqivexa and other archivers.

Use each tool for the formats and operations it supports.

How is Arqivexa different from a traditional archiver?

Arqivexa focuses on opening its own .cfs archive as a File Explorer workspace, supplying file data on demand, and saving supported edits back. Tools such as 7-Zip support a broader range of archive formats and compression workflows. Choose a tool that explicitly supports the formats, encryption, and command-line features you need.

Can I use Arqivexa alongside another archiver?

Yes. Arqivexa is not a drop-in replacement for every feature of an established multi-format archiver. They can be used side by side for the tasks each supports.

07 / TROUBLESHOOTING

If an archive will not open.

Check the extension, Windows feature, and storage location first.

Are all files ending in .cfs Arqivexa archives?

No. The extension is not globally unique; another application may use .cfs for an unrelated format. Renaming a ZIP or another archive to .cfs does not convert it.

What should I check about Windows and ProjFS?

The current release targets Windows 11 x64 and uses Windows Projected File System for the Explorer workspace. Finish setup and restart if Windows enabled the feature during installation.

What should I check about storage?

Writable archives need local NTFS storage. If a file may be damaged or from an unsupported release, keep the original copy and consult the release notes before attempting recovery.
