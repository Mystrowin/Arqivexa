What 0.6 changes

Open a .cfs archive as a managed workspace.

Arqivexa 0.6 uses Windows Projected File System to present supported archive contents through the workspace it opens. Applications can work with files through that projected path, subject to normal compatibility limits. The maintenance update also preserves edits that arrive while a save is completing.

0.6 RELEASE BOUNDARY

The archive is not a system folder.

The .cfs file is still an archive. Arqivexa 0.6 does not map it over C:\Program Files or another existing directory, provide pre-login access, or replace the Windows file system. Writable archive support targets Windows 11 x64 and local NTFS.
