01

A focused Windows workflow

From folder to compressed archive—and back.

01

Create or open in Explorer

Create an empty archive, compress a folder, or double-click an existing archive. The management app is not required.

02

Mount in Explorer

Browse projected files through Windows File Explorer without extracting the entire archive first.

03

Save and unmount

Save supported changes back into the archive, validate it, and close the mounted folder cleanly.

Consent-first updates

Release information

Stable within a focused support scope.

Use Arqivexa 0.5.0 on Windows 11 with writable archives on local NTFS storage. Keep independent backups. Arqivexa compresses files but does not encrypt them.
