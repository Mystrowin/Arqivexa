CLIENT-PROJFS

Explorer mounting uses Windows Projected File System.

Setup checks the Windows feature and may require a restart. Arqivexa reports clearly when ProjFS is unavailable.

Stable within a focused support scope.

Use Arqivexa 0.5.0 on Windows 11 with writable archives on local NTFS storage. Keep independent backups. Arqivexa compresses files but does not encrypt them.
