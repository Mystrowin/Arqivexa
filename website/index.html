01 / THE WORKSPACE

An archive that stays an archive.

Arqivexa projects a supported archive’s directory structure in Explorer. It supplies file contents when requested, then saves supported changes back into the archive.

BROWSE01

See the folder structure first.

Windows Projected File System presents the archive tree without extracting every file up front.

OPEN02

Read file data when needed.

When an application requests a file, Arqivexa retrieves and decompresses its contents through the projected workspace.

SAVE03

Keep supported edits.

Supported changes can be committed into the archive. Arqivexa validates the replacement before promoting it.
