Arqivexa / Install

Windows 11 x64

Install Arqivexa 0.5.0 Stable and prepare Explorer mounting.

The supported setup installs the Arqivexa command/broker workflow and Explorer integration. Projected File System is required for the default on-demand Explorer mount.

Get the installer↓Verify it first →
01

Before setup

Check the supported environment.

Windows 11 x64

Arqivexa 0.5.0 Stable targets 64-bit Windows 11.

Local NTFS

Writable .cfs archives must be stored on a local NTFS volume in the current Stable support scope.

Back up important files

Do not use Arqivexa as the only copy of important or irreplaceable data.

03

Projected File System

Enable ProjFS when the installer requests it.

Setup checks the feature

The installer checks for Windows Projected File System (Client-ProjFS) and can request approval to enable it.

A restart may be required

Windows can require a restart after enabling the feature. Complete that restart before expecting the Explorer mount to work.

No silent extraction fallback

If ProjFS is unavailable, Arqivexa reports the problem rather than silently pretending a full extraction is the normal mounted workflow.

04

First use

Open or create a .cfs archive.

Open

Double-click an existing archive after installation to start its managed Explorer workspace.

Create

Use the supported Explorer creation commands to create an empty archive or compress supported files into a new .cfs.

Close safely

Allow pending changes to save, then close/unmount the workspace. Resolve any reported recovery or commit error before assuming the archive is current.
