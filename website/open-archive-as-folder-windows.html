Folder-like archive access

Open a compressed archive as a folder in Windows File Explorer.

Arqivexa is designed so a supported .cfs archive can be opened as a folder-like Explorer workspace. You browse its directory tree normally while file contents are supplied on demand.

Download 0.5.0 Stable→How ProjFS makes this work →
01

What you see

An archive represented as an Explorer workspace.

Normal directory navigation

Folders and filenames from the archive appear in a projected directory tree. Explorer can enumerate them without first expanding the entire compressed payload.

On-demand file access

When a file is opened, Arqivexa supplies the requested data from the archive. This process is commonly called hydration in Projected File System terminology.

Persistent supported changes

The workspace is not intended to be a read-only preview. Supported edits can be committed back to the archive so the single user-managed .cfs file remains the persistent object.

02

Archive mounting

Is this the same as mounting a disk image?

Not exactly. People often search for terms such as mount archive as folder, mount compressed archive Windows, or open archive in Explorer. Arqivexa uses those ideas at the user-interface level, but its current implementation is a projected filesystem workspace backed by a .cfs archive, not a block-device filesystem or virtual disk.

ProjFS projection

Windows Projected File System provides the placeholder and on-demand file mechanisms used by the Explorer workspace.

Archive backing

The source of truth is the compressed archive. Arqivexa translates between archive metadata/data and the projected directory view.

Close cleanly

Closing the workspace gives Arqivexa an opportunity to commit supported changes, validate the archive state and release the projection cleanly.

03

Use cases

When a folder-like archive is useful.

Large archive, small edit

If only one or two files need attention, a projected workflow can avoid extracting every archive member before you begin working.

Explorer-centered work

Users can stay in familiar Windows File Explorer instead of managing a separate extraction directory and rebuilding the archive manually.

One portable file

When closed, the archive remains a single .cfs file that can be copied, moved or stored like another file.

Support scope

Current support is intentionally narrow.

Arqivexa 0.5.0 Stable targets Windows 11 x64. Writable archives require local NTFS storage and the Windows Projected File System feature. It does not claim to mount arbitrary ZIP, 7z, RAR or other archive formats as editable workspaces.
