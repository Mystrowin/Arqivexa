Arqivexa / What is Arqivexa?

Technical overviewWindows 11 x64

What is Arqivexa? A compressed archive that opens like a Windows folder.

Arqivexa 0.5.0 Stable works with a single .cfs compressed archive as a folder-like workspace in File Explorer. It uses Windows Projected File System for on-demand access and saves supported changes back into archives on local NTFS storage.

03

Common questions

What to know before using Arqivexa.

Does Arqivexa extract everything first?

No. It uses ProjFS to project the directory structure and supplies file contents on demand.

Where is 0.5.0 supported?

Windows 11 x64 with writable archives stored on local NTFS volumes.

Does Arqivexa encrypt archives?

No. It compresses archive contents but does not encrypt them. Keep independent backups and use separate protection when confidentiality is required.
