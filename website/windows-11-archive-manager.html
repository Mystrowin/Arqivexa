Product-category guide

Where Arqivexa fits as a Windows 11 archive manager.

Arqivexa 0.5.0 Stable is a focused archive utility for Windows 11 x64. It creates and opens its own .cfs format, uses File Explorer as the working interface, persists supported edits, and can optimize archive history after a workspace closes.

01

Core archive tasks

Create, open, browse, edit, and optimize.

Create archives

Arqivexa can create an empty supported archive or build an archive from a folder, producing a single .cfs file.

Open through Explorer

Supported archives can be opened into a projected File Explorer workspace where directory entries are visible before every file is hydrated.

Edit and persist

Supported file operations can be saved back into the archive. The Optimize operation can later remove obsolete archive history after the workspace is closed.

02

What makes it different

Explorer is the primary interface, not just a destination.

Folder-like interaction

The archive is presented as a workspace that can be navigated with familiar Explorer behaviors rather than only through a separate archive-browser window.

On-demand hydration

Arqivexa uses Windows Projected File System so file data can be supplied as requested instead of fully extracting the archive before browsing begins.

Focused format support

The tradeoff is scope. Arqivexa is not a universal multi-format archive utility. The current stable workflow centers on its own .cfs format.

03

Where it fits

Choose Arqivexa for the workspace model, not for maximum format coverage.

Good fit: persistent editable archives

Arqivexa is aimed at users who want one compressed file to reopen as a working Explorer workspace with supported edits preserved.

Good fit: Windows-native exploration

The ProjFS design is specifically useful when familiar File Explorer behavior and on-demand file access matter more than cross-platform portability.

Different fit: traditional archivers

If you primarily need broad ZIP, 7z, RAR, TAR, command-line ecosystems, or cross-platform compatibility, mature traditional archive tools cover a wider range of formats.

04

Requirements

Designed for a specific Windows configuration.

Windows 11 x64

The current supported release targets 64-bit Windows 11.

Local NTFS for writes

Writable archives are supported on local NTFS storage in the current release.

Projected File System

Explorer mounting depends on the Windows Projected File System optional feature and may require a restart during setup.

Not a replacement for every archive tool

Choose based on the format and workflow you need.

Arqivexa 0.5 is focused on editable .cfs workspaces on Windows 11. Its narrower format scope is a deliberate tradeoff for the Explorer-first workspace model.
